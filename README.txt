GoPocket - separated files

Files:
- index.html: page structure and CDN libraries
- styles.css: all CSS styles
- app.js: React/Redux/JSX application logic

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser with internet access.
3. For best results, use VS Code Live Server.

Note: React, ReactDOM, Redux Toolkit, Chart.js, icons, fonts, and Babel are loaded from CDNs, so an internet connection is required.
